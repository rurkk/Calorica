Локальное Android-приложение для учёта еды, калорий и БЖУ.

## MVP

- дневник на сегодня с итогами по калориям и БЖУ;
- встроенный каталог продуктов и создание своих продуктов;
- добавление, редактирование и удаление записей;
- ручные дневные ориентиры;
- журнал веса.

Данные сохраняются локально на устройстве. Историческая запись содержит рассчитанный снимок пищевой ценности, поэтому позднее изменение карточки продукта не переписывает дневник.

## Локальная сборка

Укажите Android SDK в `local.properties`:

```properties
sdk.dir=/path/to/Android/sdk
```

Затем выполните:

```bash
./gradlew :app:assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## CI/CD

`Android CI` запускает unit-тесты и debug-сборку для pull request и изменений Android-кода в `main`.

`GitHub release` запускается вручную, создаёт prerelease в GitHub и прикладывает debug APK. Для доставки в Google Play потребуется отдельная настройка подписи и доступа к Play Console.
