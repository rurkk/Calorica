# Совместимость, удобство и доступность

| ID | Требование | Проверка |
| --- | --- | --- |
| NFR-UX-01 | Клиент MVP — русскоязычное Android-приложение, Android 8.0/API 26 и выше; отдельные web/iOS-клиенты не входят в объём | Установка release APK и основные сценарии на API 26, одном промежуточном API и актуальном стабильном API на момент сдачи; фактические версии записаны в протоколе |
| NFR-UX-02 | Основной сценарий рассчитан на смартфон в портретной ориентации, ширина 360–480 dp; большой экран может использовать одноколоночный интерфейс | Проверка крайних размеров, клавиатуры, системных отступов; все действия достижимы, текст не закрывает ввод. Отдельный планшетный/ландшафтный дизайн не требуется |
| NFR-UX-03 | При масштабе шрифта 100%, 150% и 200% основные формы остаются работоспособными; прокрутка допустима | Регистрация, карточка, дневник, профиль и аналитика: нет скрытых обязательных полей или недостижимого сохранения |
| NFR-UX-04 | Интерактивные цели не меньше 48×48 dp; иконки-действия имеют понятные accessibility-названия; ошибки не передаются только цветом | Проверка семантики и размеров, проход основных сценариев с TalkBack |
| NFR-UX-05 | Контраст обычного текста ≥ 4,5:1, крупного ≥ 3:1; графики имеют числовые подписи/доступную текстовую сводку | Проверка выбранных цветов и чтения данных без различения цветов; декоративные элементы не засоряют TalkBack |
| NFR-UX-06 | Из открытого дневника добавление существующего продукта проходит без обязательного заполнения профиля или выхода блюда | Поиск/выбор → количество и лейблы → сохранение; дата/время предзаполнены, дополнительные настройки не блокируют путь |
| NFR-UX-07 | У каждого загружаемого экрана различимы загрузка, данные, пустое состояние и ошибка; ошибка ввода указывает поле и способ исправления | Пустой аккаунт, неверный ввод и недоступный сервер; ошибка не стирает остальные поля текущей формы |
| NFR-UX-08 | Момент хранится в UTC, календарная группировка использует переданный IANA-пояс; смена пояса не переписывает запись | Проверка UTC, Europe/Moscow и зоны с DST на границе дня/месяца и переходе времени; выбранные периоды и делитель среднего соответствуют локальному календарю |
| NFR-UX-09 | Десятичные вводы поддерживают точку и запятую как разделитель, без неоднозначных разделителей тысяч; значения не проходят через Float/Double | Одинаковый результат для 12,5 и 12.5; ошибки для неоднозначного ввода, round-trip точных долей и NULL/1 |
| NFR-UX-10 | Показатели следуют правилам точности; округление подписей не меняет сохранённые значения и расчёт итога | Контрольные примеры из политики чисел, редактирование без изменения исходного значения |

API 26 соответствует текущему `minSdk` проекта. Версию target/compile SDK определяет
сборка; это не обещание поддержки всех будущих Android без проверки.
Работа без сети ограничена уже показанными данными в памяти; после завершения процесса
офлайн-доступ и восстановление незавершённой формы не гарантируются.

Размеры целей и контраст основаны на
[рекомендациях Android по доступности](https://developer.android.com/guide/topics/ui/accessibility/apps).

[точность чисел](../../architecture/numeric-precision.md),
[UTC и часовые пояса](../../architecture/runtime-policies.md).
