# Стартовый базовый каталог

## Объём и наполнение

В MVP база данных первично заполняется миграцией: около 50 распространённых
продуктов. Стартовый набор может включать конечные и действительно нужные составные
продукты.

Для каждой записи миграция задаёт необходимые данные: название, КБЖУ, продуктовые
лейблы и, когда применимо, коэффициенты конвертации для миллилитров. Для составного
продукта миграция дополнительно задаёт валидные дочерние связи с массовыми долями 100%
и без циклов.

## Источники

Значения КБЖУ берутся из открытых источников. Они не отображаются в пользовательском
интерфейсе; в миграции остаются комментарии о происхождении соответствующих данных.

## Управление

После первичного заполнения базовый каталог и общий набор продуктовых лейблов
редактирует только Admin через мобильное приложение.
