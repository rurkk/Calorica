# Единицы измерения

## Базовое правило

Каноническая единица количества, хранения и расчётов в MVP — **грамм**. КБЖУ продукта
задаются на 100 г, а запись дневника хранит итоговое количество только в граммах.

## Справочник и конвертация

1. В MVP справочник единиц измерения содержит «грамм» и «миллилитр».
2. Таблица конвертации связывает конкретный продукт, единицу измерения и коэффициент
   перевода этой единицы в граммы.
3. Для введённого значения сервер применяет коэффициент и сохраняет результат в
   граммах.
4. Граммы доступны для продукта всегда. Иная единица доступна только при наличии для
   продукта соответствующей записи конвертации.
5. Личный продукт в MVP создаётся только с граммами; коэффициент для миллилитров для
   него не задаётся.

## Развитие

Справочник и таблица конвертации намеренно рассчитаны на будущие единицы: стакан, яйцо,
ложка, порция и другие. Их правила конвертации будут определены отдельно.
