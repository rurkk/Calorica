# Каталог продуктов

## Функциональные требования

- **FR-CAT-01. Базовый каталог.** Любой пользователь может просматривать и добавлять в
  дневник продукты из общего базового каталога.
- **FR-CAT-02. Личные продукты.** Пользователь может создавать, редактировать и мягко
  удалять только свои продукты. Они видны только владельцу.
- **FR-CAT-03. Данные конечного продукта.** Для конечного личного продукта пользователь
  задаёт название и ручные калории, белки, жиры и углеводы на 100 г. Правила дальнейшего
  превращения в составной продукт описаны в [графе продуктов](../domain/product-composition-graph.md).
- **FR-CAT-04. Права на базовые сущности.** Создавать, редактировать и мягко удалять
  базовые продукты может только Admin. Кнопки создания, редактирования и удаления
  базовых продуктов, а также управления общими продуктовыми лейблами отображаются
  только у Admin. У обычного пользователя эти кнопки скрыты; кнопки редактирования и
  удаления продуктов отображаются только для его собственных личных продуктов.
  Сервер независимо от видимости кнопок проверяет права на каждое действие.
- **FR-CAT-05. Состав продукта.** Пользователь может создавать составной личный продукт
  из доступных ему базовых и собственных продуктов, указывая массу каждого ингредиента
  в граммах. Общую исходную массу и доли вычисляет сервер; ввод процентов не требуется.
  В связях состава сохраняются только ссылки на ингредиенты и их доли, не массы.
  Администратор может так же работать
  с базовыми составными продуктами, включающими только продукты базового каталога.
  Правила состава описаны в
  [графе продуктов](../domain/product-composition-graph.md).
- **FR-CAT-06. Поиск.** Каталог поддерживает гибкий поиск по названию среди базовых и
  личных продуктов текущего пользователя. Поиск исключает мягко удалённые продукты.
- **FR-CAT-07. Ранжирование.** Точные и префиксные совпадения показываются прежде
  похожих; результаты с опечатками находятся по триграммному сходству.
- **FR-CAT-08. Фильтр по лейблу.** Пользователь может отфильтровать каталог по одному
  выбранному продуктовому лейблу. Множественный выбор лейблов не входит в MVP.
- **FR-CAT-09. Выход готового блюда.** Для расчёта по составу карточка поддерживает
  коэффициент выхода, по умолчанию равный `1`. Масса всего готового блюда при создании
  необязательна; без её указания коэффициент равен `1`. Настройка находится в
  дополнительном свёрнутом блоке и не усложняет основной сценарий. Сервер сохраняет
  рассчитанный коэффициент, но не массы ингредиентов или готового блюда. Масса,
  введённая при настройке карточки, не означает съеденное количество и не создаёт
  запись питания. Формулы, ограничения
  и поведение редактирования приведены в [правилах выхода](../domain/cooking-yield.md).

## Правила поиска

- Исходное название сохраняется для отображения.
- Сервер формирует отдельное нормализованное поисковое значение и применяет ту же
  нормализацию к запросу: нижний регистр, `ё → е`, `ъ → ь` и другие согласованные
  преобразования.
- Поиск использует PostgreSQL `pg_trgm` и GIN-индекс по нормализованному значению.
- Запросы длиной в один или два символа ищутся по началу нормализованного названия;
  триграммная похожесть для них недостаточно информативна.

## Не входит в MVP

- альтернативные названия и синонимы продуктов;
- полнотекстовый поиск;
- фильтры по калориям и БЖУ;
- «недавние продукты», избранное и рекомендации.
