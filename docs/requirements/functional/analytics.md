# Аналитика

## Экран «Анализ»

В MVP есть один экран «Анализ» с выбором даты и компактным переключателем периода:
**день**, **неделя**, **месяц**. По умолчанию выбрана сегодняшняя дата. Все показатели
рассчитываются сервером при запросе из актуальных нормализованных данных.

## Функциональные требования

- **FR-AN-00. Выбранная дата.** Пользователь может выбрать дату для анализа. По
  умолчанию используется сегодняшний день.
- **FR-AN-01. Сводка.** Вверху экрана показываются средние калории, белки, жиры и
  углеводы за выбранный период.
- **FR-AN-02. Полные календарные периоды.** Среднее считается по всем календарным дням
  периода; день без записей даёт нулевой вклад.
- **FR-AN-02a. Границы периода.** При детализации по дню отображается выбранная дата;
  неделя — календарный период с понедельника по воскресенье, а месяц — с первого по
  последнее число месяца, содержащего выбранную дату. Скользящие окна последних 7 или
  30 дней не входят в MVP.
- **FR-AN-03. Динамика калорий.** Столбцы показывают калории по дням, а линия — личный
  дневной ориентир по калориям, если он задан.
- **FR-AN-04. Радар баланса.** Лучевая диаграмма сравнивает средние калории, белки,
  жиры и углеводы с соответствующими личными ориентирами.
- **FR-AN-05. Незаполненные ориентиры.** На оси без ориентира отображается только
  фактический показатель, без целевой точки и оценки покрытия.
- **FR-AN-06. Масштаб радара.** Контур может выходить за 100%. Шкала автоматически
  расширяется, но визуально ограничена 150%; превышение 150% отображается точкой на
  внешней границе и подписью с фактическим процентом.
- **FR-AN-07. Продуктовые лейблы.** Столбцы показывают массу в граммах по продуктовым
  лейблам. Лейблы могут пересекаться, поэтому сумма столбцов может превышать общий вес
  рациона.
  Для составов распределяется масса съеденной готовой порции по долям ингредиентов,
  без деления на коэффициент выхода. Интерфейс поясняет: «Вес готовой порции,
  распределённый по составу». Это не измеренная масса ингредиентов после приготовления
  и не пересчёт в исходное сырьё. Например, при коэффициенте `0,8` съеденные 200 г
  распределяются как 200 г. Подробнее — [выход готового блюда](../domain/cooking-yield.md).
- **FR-AN-08. Лейблы приёмов пищи.** Столбцы показывают суммарные калории по лейблам
  приёмов пищи. Запись с несколькими лейблами учитывается в каждом из них.

## Закладка на будущее

Для столбцов по лейблам приёмов пищи модель и API должны позволять переключить метрику
с калорий на белки, жиры или углеводы. В интерфейс MVP этот переключатель не входит.

## Границы

Аналитика не выносит медицинских оценок и не даёт автоматических рекомендаций.
