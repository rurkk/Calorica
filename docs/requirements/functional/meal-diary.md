# Дневник питания

## Функциональные требования

- **FR-DIARY-01. Просмотр по датам.** Пользователь просматривает дневник для любой
  выбранной даты, включая прошлые даты.
- **FR-DIARY-02. Добавление.** Пользователь добавляет доступный продукт в дневник,
  указывая количество и один или несколько лейблов приёма пищи.
- **FR-DIARY-03. Время.** При создании записи время автоматически заполняется текущим,
  но пользователь может его изменить.
- **FR-DIARY-04. Редактирование.** Пользователь может изменить продукт, дату, время,
  лейблы приёма пищи, количество и единицу ввода записи.
- **FR-DIARY-05. Удаление.** Пользователь может удалить свою запись дневника.
- **FR-DIARY-06. Количество.** Пользователь выбирает только доступную выбранному
  продукту единицу, а сервер перед сохранением приводит количество к граммам. Подробнее —
  в [правилах единиц измерения](../domain/units-of-measurement.md).
- **FR-DIARY-07. Актуальные КБЖУ.** В записи не редактируются калории и БЖУ. Они
  рассчитываются по актуальной карточке выбранного продукта при запросе дневника и
  аналитики.

## Границы

- В записи не сохраняется единица, в которой пользователь ввёл количество; хранится
  итоговое количество в граммах.
- В записи не сохраняется снимок КБЖУ продукта.
- Удаление продукта или зависимого состава не удаляет связанные записи дневника и
  не исключает их из аналитики. Количество остаётся в граммах, КБЖУ продолжают
  рассчитываться по сохранённой в базе карточке продукта.
- Изменения карточки продукта, его состава или лейблов ретроспективно меняют показатели
  всех связанных записей и их аналитики.
