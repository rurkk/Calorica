# Журнал продуктовых решений

Этот каталог сохраняет существенные решения, принятые до подготовки ТЗ. Если решение
изменяется, его нужно обновить здесь и в тематическом документе-источнике.

## Принятые решения

- Клиент MVP — мобильное приложение с серверной частью.
- В MVP есть регистрация, вход и выход по e-mail и паролю; подтверждение e-mail,
  восстановление пароля и Google-вход отложены.
- Расчёты выполняются сервером по актуальным нормализованным данным; снимок КБЖУ в
  записи дневника не хранится.
- «Блюдо» не является отдельной сущностью: его роль выполняет составной продукт в
  ациклическом графе продуктов.
- Все изменения требуют сети; кэш используется только для просмотра.
- MVP не содержит автоматических рекомендаций, медицинских выводов или AI-диетолога.
- Фильтр каталога выбирает один продуктовый лейбл за раз.
- Удаление общего продуктового лейбла удаляет все его связи с продуктами.
- Аналитика использует календарные неделю и месяц, а не скользящие окна.
- Admin не может каскадно удалить базовый продукт, если это затронет личные составы
  других пользователей.
- При регистрации личные ориентиры остаются пустыми; пользователь добровольно
  заполняет их только после регистрации в профиле, без значений по умолчанию.
- Удаление продукта, в том числе каскадное удаление зависимых составов, сохраняет
  записи питания и их участие в аналитике. КБЖУ по-прежнему берутся из актуальной
  карточки, количество хранится в граммах; снимок КБЖУ не создаётся.
- Кнопки управления базовыми продуктами и общими продуктовыми лейблами скрыты у
  обычного пользователя и отображаются только у Admin.
- Стартовый каталог содержит около 50 продуктов и заполняется миграцией.

## Отложенные темы

- дополнительные единицы измерения и их конвертация;
- пользовательские лейблы приёмов пищи;
- альтернативные названия и полнотекстовый поиск;
- избранное, недавние продукты и рекомендации;
- автоматический расчёт личных ориентиров по данным профиля;
- офлайн-очередь изменений и разрешение конфликтов;
- вход через Google, восстановление и смена пароля;
- штрихкоды, распознавание продуктов по фото и AI-диетолог.
