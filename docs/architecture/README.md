# Архитектура семестрового MVP Calorica

Актуальное описание: [архитектура третьего этапа](../semester-mvp/stage-3/architecture.md).
Объём функций: [Android и серверный API](../semester-mvp/scope.md).

## Согласованные решения

- Android: Kotlin и Compose, формы, состояние экранов и запросы к API.
- Сервер: Kotlin/Spring Boot, модульный монолит, Spring JDBC и явный SQL.
- PostgreSQL хранит нормализованные данные; расчёты выполняются при чтении.
- Продукты образуют ациклический граф; сохраняются доли и заданные коэффициенты.
- Изменения графа сериализуются по владельцу. Протокол с ключом базового каталога
  описан в третьем этапе и защищает гонки удаления с созданием зависимостей.
- Один репозиторий, независимые сборки и выпуски Android и сервера.
