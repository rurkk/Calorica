# Протокол проверки приложения для этапа 4

4 ноября 2026 года, Europe/Moscow. Проверку выполнил Codex: действия в Android
через ADB/UI Automator, чтение видимых состояний и оригинальные PNG через screencap.
Для ключевых чисел дополнительно прочитан API той же локальной БД.
**19 сценариев PASS.** Это свежая проверка интерфейса для материалов этапа 4;
полные автоматические наборы в рамках подготовки презентации не запускались повторно.

## Проверенная версия

- Исходники: PR44, `9130aaa517e020e1cd43e0790de645343a57e01e`.
- APK: `com.rurkk.calorica.localpr44`, версия 0.1.3, code 4, debug.
- Устройство: эмулятор `Calorica_PR44`, Android 16 / API 36, портретная ориентация.
- Локальный backend: HTTPS, порт 18444; PostgreSQL 17.11, восемь миграций.
- Использованы отдельный Android-профиль и синтетический аккаунт.
  Общая БД и пользовательский аккаунт не участвовали в изменениях.
- Полные хеши APK/JAR и настройки: [versions.json](evidence/versions.json).

## Доказательства и повтор съёмки

[checks.json](evidence/checks.json) содержит время первоначального успешного
прохождения каждого сценария. [screenshots.json](evidence/screenshots.json)
содержит время и SHA-256 последнего сохранённого снимка. Часть показательных действий
повторена для съёмки после окончания загрузки: заново создан Outer с теми же
ингредиентами и повторена последовательность 600 → 300 → 600 → 725 ккал.
Это не дополнительные сценарии и не увеличение счётчика проверок.

Изображения — неизменённые PNG эмулятора. На слайдах применено только кадрирование
средствами PowerPoint для читаемости; полные оригиналы доступны в [screenshots/](screenshots/).
Пароли и токены отсутствуют. Адрес с доменом example.test относится к созданному
демонстрационному аккаунту. Ответы `api-*.json` содержат только его контрольные данные.
Идентификаторы повторно созданного Outer отличаются от первоначального прогона.

Связи файлов со сценариями, версиями и контрольными суммами собраны в
[manifest.json](evidence/manifest.json). Доклад и подписи используют фактические
контрольные значения, а не макеты интерфейса.

## Прежние проверки и границы

113 Android JVM, 37 backend unit и 111 интеграционных PostgreSQL тестов относятся
к ранее выполненным прогонам. Их SHA, команды, источники и отдельная проверка
успешного CI PR44 приведены в [baseline-tests.json](evidence/baseline-tests.json).
Сложные серверные сценарии, fault-серия и сохранность описаны в
[отчёте](implementation-report.md); этот UI-прогон их целиком не повторяет.

Физического Android нет. Merge и выпуск PR44 отложены пользователем; release jobs
не выполнялись. Текущая опубликованная старая версия несовместима с новыми составами
при возврате. Полная приёмка T18 остаётся открытой. Сам комплект этапа 4 пригоден
для показа локальной реализации с этими явно указанными ограничениями.
