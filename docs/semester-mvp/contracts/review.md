# Независимое ревью T00

1 ноября 2026, рецензент — отдельный агент 2 (review_t00), владелец — агент 1.
Рассмотрены OpenAPI/fixtures, README контрактов, миграционный реестр, аудит,
acceptance, T17 и ТЗ. Ревью не является ручной приёмкой человека.

Найденные блокирующие замечания и исправления:

1. Создание нового состава требовало сначала конечный продукт с ручными КБЖУ.
   Исправлено: ProductCreate oneOf конечный либо атомарный name+composition,
   manualNutrition=NULL допустим; добавлен frozen create-composite.
2. Неявная изоляция write transaction могла оставить устаревший snapshot после
   ожидания advisory lock. Исправлено: READ COMMITTED для мутаций, lock и проверки
   отдельными SQL statements; REPEATABLE READ только для согласованного чтения.

Повторное независимое ревью: оба замечания устранены, новых блокеров нет,
одобрено для интеграции. Рецензент самостоятельно выполнил validate.py:
26 paths, 34 operations, 7 fixtures с format checker, 8 миграционных резерваций,
локальные ссылки; git diff --check успешен. Дополнительное редакционное уточнение
про READ COMMITTED для unit/label mutations учтено в e05b69b.

SA-17 одинаков в acceptance/T17/ТЗ, действующий Render/Neon отделён от исторического
VPS. Расчётные интерфейсы не размножают формулы; 010/020 миграции независимы,
