## Сборка и проверка

Сборщик [build_documents.py](build_documents.py) использует общий модуль оформления
`scripts/build_stage2.py`, не изменяя его и не перезаписывая прежние документы.
Запускать Python с зависимостями `python-docx` и `pypdf`:

```text
python -B docs/semester-mvp/stage-2/build_documents.py
```

Затем отрендерить DOCX штатным документным окружением, проверить все страницы,
поместить проверенный PDF рядом и запустить:

```text
python -B docs/semester-mvp/stage-2/build_documents.py --check
```

Проверка сверяет текст исходника, ID требований и набор страниц в обоих форматах.
Изменение исходника требует пересборки и повторной визуальной проверки.
