## Общие незакрытые условия

На проверенной main `b134ada` [Backend CI](https://github.com/rurkk/Calorica/actions/runs/42391619539)
завершён с `failure`. Аннотации jobs `changes` и `required` подтверждают:
`The job was not started because your account is locked due to a billing issue.`
Это проверенный внешний блокер запуска, а не результат исполнения тестов.

| ID | Факт | Действие для закрытия |
| --- | --- | --- |
| CI-1 | Последние Actions завершались до выполнения шагов из-за billing lock; новых успешных main CI нет | После снятия блокировки выполнить обязательные проверки точного кандидата; локальные PASS не подменять зелёными check-runs |
| DELIVERY-1 | Новый backend доставлен точным commit через Render, но нет опубликованного нового digest образа приложения в GHCR | Собрать/опубликовать совместимый образ, зафиксировать digest/revision; вернуть Render на image с этим digest и перепроверить готовность/API |
| PHYSICAL-1 | Проверен эмулятор API 36 и Robolectric на API 26/35; физического Android нет | Записать модель и API устройства; выполнить основной сценарий и сценарии сбоев на реальном устройстве |

«Подтверждено автоматикой/локально» ниже означает доказательство уже выполненной проверки. Наличие исходника теста само по себе не отмечается как новое исполнение. «Не зафиксировано на выпуске» означает отсутствие требуемого доказательства, а не объявление функции нереализованной.
