# Calorica — минимальная реализация на семестр

Версия 0.2 · 8 октября 2026 года.

Отдельный план семестровой реализации с последовательностью работ,
проверяемыми результатами и правилами разработки с агентами.

## Документация реализации

Эта папка определяет состав семестровой поставки, правила реализации и критерии
приёмки. [Комплект второго этапа](stage-2/README.md) содержит ТЗ в DOCX/PDF,
короткий доклад и чек-лист сдачи.

## Что сдаём

Работающий Android-клиент и сервер: пользователь входит, находит или создаёт продукт,
создаёт состав, записывает съеденное и видит дневные КБЖУ. APK устанавливается,
сервер развёрнут, данные сохраняются, критические правила проверены.

Домен реализуется и проверяется на сервере. Пользовательские сценарии демонстрируются
в Android, серверные операции — через API и автоматические тесты.

## Контроль реализации

Первый сквозной сценарий проверяет выбранный стек и взаимодействие клиента с сервером.
Следующие шаги опираются на результаты интеграции и проверок. Изменения объёма
согласуются явно; требования к доступу, расчётам и сохранности данных остаются
обязательными.

Эта редакция содержит только документацию. Реализация, испытания и развёртывание
не подтверждены самим фактом появления плана.
