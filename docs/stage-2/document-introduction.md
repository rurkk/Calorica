# Общие сведения

## Основание разработки

Техническое задание определяет объём разработки мобильного приложения Calorica
с серверной частью на семестр. Документ предназначен для команды проекта и проверки
результатов второго учебного этапа. Он содержит функциональные и нефункциональные
требования, правила предметной области, бизнес-процессы, план работ и критерии приёмки.

Основание разработки — задание второго этапа учебного проекта: спланировать объём
работ, сформулировать требования и оформить техническое задание. Тема проекта
сохраняется на протяжении семестра.

Требования описывают целевое приложение. Числовые показатели качества являются
условиями будущих испытаний, а не результатами измерений текущей реализации.
Версия ТЗ — 0.2 от 28 сентября 2026 года.

## Сокращения

- MVP — первая версия, реализующая согласованный обязательный объём.
- КБЖУ — калории, белки, жиры и углеводы; БЖУ измеряются в граммах, калорийность — в ккал.
- API — интерфейс взаимодействия мобильного приложения и сервера.
- UTC — единая временная шкала хранения моментов; календарные дни определяются в часовом поясе клиента.
- p95 — время, в которое укладывается не менее 95% измеренных запросов.
- RPO — допустимый интервал потери данных при аварии.
- RTO — целевое время восстановления сервиса после обнаружения аварии.
- CI/CD — автоматические проверки, сборка, выпуск и доставка изменений.
