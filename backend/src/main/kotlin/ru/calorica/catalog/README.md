# catalog

Продукты, граф, выход, единицы, лейблы и единый расчётный SQL. Реализация отложена.

При добавлении сценариев используем пакеты `api`, `application`, `domain`, `persistence`.
Транзакции и проверка прав — в application; SQL — в persistence.
Взаимодействие с другими модулями — через операции application, без записи в чужие таблицы.
Не добавлять заглушки маршрутов или репозиториев.
